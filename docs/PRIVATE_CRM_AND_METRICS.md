# Confidential CRM and Metrics Rules

**Public GitHub is NOT a CRM.** Use a restricted company-approved sheet or CRM for prospect-level data. Never paste emails, phone numbers, names of people tied to private conversations, call recordings, WhatsApp screenshots, draft contracts, passwords or payment records in public issues.

## Private college tracker fields
Internal lead ID; institutional name; official website; programme fit; source date; public official contact department/channel; contact consent/opt-out; owner; date of first attempt; attempted vs connected; conversation result; MoU discussion offered/requested/accepted/held; decision maker; next action date; compliance/approval notes.

## Private software-client tracker fields
Lead ID; company; official web source; business problem/fit; channel; consent/opt-out; attempt date; response status; qualification; proposed technical discussion; owner; next action and follow-up count. Access only approved staff.

## Counts in public GitHub
Colleges researched today/cumulative; colleges approached today/cumulative; actual replies; MoU discussions requested vs held vs signed; software businesses researched; two *unique* businesses approached; replies and discovery meetings; blockers and next steps.

## Reconciliation
Avoid duplicate leads, distinguish call attempted from connected; record actual zero if no contact. College or company names only in private CRM, not the daily public comments unless information is independently official and publication has management approval. Do not infer a client from a proposal.
