# Calling Intern साठी मराठी सूचना — 28 दिवस

ही एक स्वतंत्र CareerPluse College Outreach आणि Heal Bharat Services Software Client Calling internship आहे. दररोज GitHub मध्ये एक Issue असेल. नावे आणि प्रत्यक्ष संपर्क तपशील public GitHub वर टाकायचे नाहीत.

## 28 दिवसांत करायचं काय?

**College:** स्वतः किमान तीन संबंधित कॉलेज शोधा. अधिकृत website वरून TPO, HOD किंवा Placement विभाग शोधा. सर्व तीन कॉलेजला योग्य professional संपर्क करा. CareerPluse चा फक्त कंपनीकडून मंजूर केलेला परिचय द्या. किमान एका कॉलेजसोबत MoU किंवा partnership बद्दल चर्चा *मागण्याचं आणि शक्य असल्यास प्रत्यक्ष चर्चा होण्याचं* लक्ष्य ठेवा. MoU स्वतः sign करायचा नाही. कॉलेजला फोन लावला म्हणजे MoU झाला असं नाही.

**Software Clients:** वेबसाइट, web app किंवा व्यावसायिक software ची गरज असू शकते असे योग्य व्यवसाय संशोधन करून शोधा. Research ला कृत्रिम संख्या मर्यादा नाही; पण blind bulk calling नाही. 28 दिवसांत किमान दोन स्वतंत्र आणि योग्य व्यवसायांना approved pitch ने approach करा. Approach झालं म्हणजे paid client मिळाला नाही.

## कामाची पद्धत
1. पहिल्या दिवशी Founder/Manager कडून official परिचय, authorised services, calling script, कंपनी SIM वापरण्याचे नियम, consent आणि tracker access घ्या.
2. [GitHub Issues](https://github.com/healbharat/CareerPluse-Calling-Partnerships-28-Day/issues) मधला Day 01 Issue उघडा; पुढे प्रत्येक working day साठी वेगळा Issue आहे.
3. कस्टमरचे नाव/नंबर, नोट्स, कॉलची वेळ, पुढचा action **private कंपनी tracker** मध्ये लिहा.
4. रोज संध्याकाळी ठरलेल्या वेळेला GitHub Issue च्या **Comment** मध्ये फक्त actual counts, blocker आणि next action लिहा. प्रतिसाद नाही तर 0 लिहा.
5. Manager review करेल आणि Founder final approval देईल.

**बोलताना:** प्रामाणिक माहिती द्या, placement किंवा signed MoU ची guarantee देऊ नका, फक्त मंजूर सेवा सांगा. परवानगीशिवाय call recording किंवा personal outreach करू नका.

**Day 28:** 3 कॉलेज approaches, MoU चर्चेचा प्रत्यक्ष status, 2 business approaches आणि सगळ्या follow-ups चा सत्य report Founder ला द्या.
